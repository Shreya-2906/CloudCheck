# 🌤️ CloudCheck

CloudCheck is a clean and simple weather forecast web app that lets users check real-time weather data for any city around the world using the OpenWeatherMap API.

🔗 [Live Demo](https://shreya-2906.github.io/CloudCheck/)

## 📌 Features

- 🌍 Get current weather data for any city
- 📊 Displays temperature, humidity, wind speed, and more
- 🎨 Clean and responsive user interface
- 🔄 Instant updates based on user input
- ☁️ Powered by the OpenWeatherMap API

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- OpenWeatherMap API

## 🚀 How to Use

1. Visit the [CloudCheck Live Demo](https://shreya-2906.github.io/CloudCheck/)
2. Enter the name of the city in the input field.
3. Click the **Search** button or press **Enter**.
4. View real-time weather data including:
   - Temperature
   - Weather Condition
   - Humidity
   - Wind Speed
   - City Name and Country Code
